Zi's ecosystem extends the plugin manager with three building blocks: **annexes** that add new capabilities, **packages** that bundle complex setups into a single ice, and a curated **plugin gallery**.

:::tip[Start with annexes]
The [bin-gem-node](/ecosystem/annexes/bin-gem-node) annex automatically manages Ruby gems, Node modules, and Python virtualenvs. Install it once via [meta-plugins](/ecosystem/annexes/meta-plugins) and everything just works.
:::
