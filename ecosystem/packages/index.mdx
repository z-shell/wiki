Find a tool, open its card, and choose an installation profile. Zi packages provide reusable configurations for installing software and setting up your shell.

New to packages? Read the [Package guide](/ecosystem/packages/guide) for setup, profiles, updates, and adding a package.

:::info[Before installing]

Load [Zi](/docs/getting_started/installation) first. Many packages also need [bin-gem-node][] or other tools listed in their cards. Review the package repository and your platform requirements before running an installation command.

:::

<PackageCard name="any-gem" description="Install Ruby gems locally with executable shims." sources={["Gem"]}>

:::info[Before you install]

Requires Ruby, RubyGems, and [bin-gem-node][]. Set `GEM` to the gem you want and use a distinct `id-as` for each installation kept in `.zshrc`.

:::

:::warning[Additional current prerequisite]

The [package manifest](https://github.com/z-shell/any-gem/blob/1acfc73f56c4fcb0c0d4705bcb532f0ebc67ca0e/package.json) also declares npm as a prerequisite. Zi enforces that declaration even though this recipe installs gems, so npm must currently be available too.

:::

#### Install with Zi {/* #any-gem-installation */}

```zi title="Installation command"
zi id-as=ruby-on-rails pack param='GEM -> rails' for any-gem
```

</PackageCard>
